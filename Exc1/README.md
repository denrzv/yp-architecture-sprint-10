# Схема потоков данных

## Сущности, участвующие в потоках:

* Пациент
* Администратор
* Доктор
* Кассир
* Работник склада
* Бухгалтер

## Хранилища данных:

* Excel-файл Журнал записи к врачам
* Excel-файл Реестр анализов
* Excel-файл Список пациентов клиники
* Файлы пациентов в разных форматах (PDF, PNG, Doc)
* 1С Бухгалтерия предприятия в файловом режиме
* 1С Торговля и склад в файловом режиме

## Верхнеуровневые процессы (Level 0):

* Управление регистрацией
* Управление платежами
* Управление ТМЦ
* Управление медицинскими данными
